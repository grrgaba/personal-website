Projects

Future DIY, electrical, and website ideas with photos, AI mockups, and phased planning so each project can grow from inspiration into something real.

How I want to build this section

Each project will start as a rough idea with reference photos, AI depictions, and notes on the overall vibe I am going for. From there I want to break things into manageable stages so I can actually plan cost, effort, and timing instead of letting everything stay in the "someday" bucket.

I also want this page to work like a living blueprint. Some entries will stay in inspiration mode for a while, while others will gradually turn into real build logs once materials are bought and progress photos start coming in.

Construction Projects

Hanging Garage Storage

Stage 1: Collect inspiration for ceiling-mounted storage layouts and decide what should live overhead versus stay accessible on the walls.

Stage 2: Measure the garage clearance, mark joists, and estimate weight limits so the system looks clean without becoming sketchy.

Stage 3: Choose materials, sketch a layout, and price out the build before buying hardware.

Stage 4: Install, load test, and photograph the final setup once everything is organized.

Rock Walkpath Landscaping

Stage 1: Save inspiration for natural-looking stone paths with edging, spacing, and lighting ideas.

Stage 2: Map the route through the yard and decide whether the goal is more aesthetic, more functional, or both.

Stage 3: Figure out base prep, drainage, rock type, and how much material is realistically needed.

Stage 4: Build section by section, then finish with photos showing before, during, and after.

Storage Shed at the Back

Stage 1: Gather inspiration for size, roof style, siding, and the overall look so it feels intentional with the backyard.

Stage 2: Check placement, access, sun exposure, and any permit or setback considerations before going too far.

Stage 3: Plan the foundation, framing, storage layout, and budget for materials and tools.

Stage 4: Build the shell first, then finish the inside once I know what it actually needs to store.

Extend the Backyard Deck

Stage 1: Build a mood board of deck extensions that improve flow, seating, and backyard usability.

Stage 2: Measure the existing deck, inspect the current structure, and identify the cleanest way to tie in the extension.

Stage 3: Plan footings, railing options, materials, and the budget so the addition looks original rather than bolted on.

Stage 4: Phase the work into demo, framing, deck boards, and finishing details.

Electrical Projects

Hand Crank Generator

Stage 1: Research existing DIY hand crank generator concepts and save diagrams that make the mechanics easy to understand.

Stage 2: Decide what I actually want it to power, even if it starts with something small like LEDs or USB charging.

Stage 3: Plan the generator, gearing, rectifier, casing, and output display so it feels like a proper project rather than a loose experiment.

Stage 4: Build a prototype first, measure output, and then redesign it if the first version looks rough.

Phone-Controlled Random Objects

Stage 1: Use this as an inspiration bucket for odd, useful, or funny things that could be controlled from my phone.

Stage 2: Split ideas into categories like practical home automation, novelty builds, and weird desk gadgets.

Stage 3: Decide which control stack makes sense for each build, whether that is Bluetooth, Wi-Fi, relays, or a microcontroller app combo.

Stage 4: Pick one small object to prototype first before going after the more chaotic ideas.
